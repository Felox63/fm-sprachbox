# FM – Sprachbox

**WhatsApp und Telegram in einer portablen Windows-App. Mehrere Konten, eine Oberfläche.**

Ein Projekt von **Felix**, entwickelt mit Unterstützung von **KI (Hermes)**.

[**Windows herunterladen · Version 1.1**](https://github.com/Felox63/fm-sprachbox/releases/latest) · [Ideen & Fehler](https://github.com/Felox63/fm-sprachbox/issues) · [Mitwirken](CONTRIBUTING.md)

## Das kann die App

- WhatsApp und Telegram mit mehreren, getrennten Konten
- Eigene Kontennamen; Konten hinzufügen, umbenennen, aktivieren und entfernen
- Optional im Tray weiterlaufen
- Windows-Benachrichtigungen – mit Inhalt, ohne Inhalt oder ausgeschaltet
- Neue-Nachricht-Punkt pro Konto
- Externe Links im Standardbrowser öffnen
- Portable Nutzung ohne Installation; Daten im lokalen `data`-Ordner

## Loslegen

1. Unter [Releases](https://github.com/Felox63/fm-sprachbox/releases/latest) die **`FM-Sprachbox-win64.zip`** herunterladen.
2. Entpacken und **`FM - Sprachbox.exe`** starten.
3. Konten hinzufügen und anmelden.

**Update:** App vollständig schließen, `data` sichern und eine Kopie in den neuen App-Ordner übernehmen. Den alten Ordner als Rückweg behalten.

**Links:** Telegram per Linksklick und Bestätigung; WhatsApp per Rechtsklick → „Im Browser öffnen“. WhatsApp-Benachrichtigungen zusätzlich in WhatsApp Web aktivieren.
